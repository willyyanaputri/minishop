# 🛍️ MiniShop

MiniShop adalah aplikasi e-commerce sederhana yang dibuat menggunakan React JS.

Project ini dibuat sebagai latihan penerapan React mulai dari component, routing,
state management, integrasi API, autentikasi, testing, optimasi, hingga deployment.

## ✨ Fitur

- 🏠 Halaman Home
- 🔍 Pencarian produk
- 🏷️ Filter produk berdasarkan kategori
- 📄 Detail produk
- 🛒 Keranjang belanja
- ➕ Menambahkan produk ke keranjang
- ➖ Mengubah jumlah produk
- 🗑️ Menghapus produk dari keranjang
- 💾 Penyimpanan keranjang menggunakan localStorage
- 🔐 Login dan Register
- 🛡️ Protected Route
- 📜 Halaman Riwayat Pesanan
- ❌ Halaman 404
- ⚡ Lazy loading halaman
- 🖼️ Lazy loading gambar produk
- 🧪 Unit testing menggunakan Vitest dan React Testing Library

## 🛠️ Teknologi yang Digunakan

- React JS
- Vite
- React Router DOM
- Tailwind CSS
- Context API
- LocalStorage
- Fake Store API
- Vitest
- React Testing Library

## 🌐 API

Data produk pada aplikasi diperoleh dari Fake Store API.

API yang digunakan:

https://fakestoreapi.com/

Endpoint utama:

- `/products` — mengambil data produk
- `/products/categories` — mengambil daftar kategori produk
